# Dogu Branding and Official Source

## Official source

The official source for Dogu is:

- Repository: <https://github.com/Otakora/dogu>
- Official releases: <https://github.com/Otakora/dogu/releases>

## Name and identity

The name `Dogu`, the project logo, and the project artwork identify the official
project and its official releases.

Forks and redistributions are welcome under the project's software license, but they
should not present themselves as the official Dogu project or imply endorsement by
the original maintainer.

Please avoid:

- Presenting a modified build as the official Dogu release.
- Using the Dogu name or logo in a way that creates confusion about authorship.
- Hiding or removing the original project attribution required by the license.

If you redistribute modified builds, please make it clear that they are modified
versions and point users to the official project source above.
